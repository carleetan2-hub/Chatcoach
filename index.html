信息只保存在你这台电脑的浏览器本地，不会上传。官方 Anthropic 接口国内直连通常需要科学上网；国内可直连的选项可以填智谱等 Claude 兼容中转地址，如 https://open.bigmodel.cn/api/anthropic。

⚠️ 如果测试连接报"无法连接"或对话第一句就报错，很可能是你填的中转/代理服务没有为浏览器直接访问开启 CORS 跨域许可——像智谱这类中转接口通常是给 Claude Code、后端 SDK 这类场景设计的，不支持网页直接调用。解决办法：部署一个免费的 Cloudflare Worker 做转发代理（几分钟就能搞定，代码已经写好了，问 Claude 要"chatcoach-cors-proxy.js"这个文件和部署步骤），部署好后把这里的 Base URL 换成你的 Worker 网址（例如 https://你的worker名.你的用户名.workers.dev/api/anthropic），API Key 和模型名不变。

每一项都可以单独清除。清除前会自动做一次备份，误删了可以在下面恢复（备份只保留最近一次，且只在这台设备的浏览器里，关闭页面前记得先导出重要内容）。
